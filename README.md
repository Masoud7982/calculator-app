# ماشین‌حساب ساده (Kivy) — چهار عمل اصلی + خروجی APK

ماشین‌حساب اندروید با پایتون و Kivy: جمع (+)، تفریق (−)، ضرب (×) و تقسیم (÷)، با طراحی تیره‌ی مدرن، دکمه‌های گرد و نمایشگر دوردیفه.

## فایل‌های پروژه

| فایل | توضیح |
|---|---|
| `main.py` | رابط کاربری Kivy (نقطه‌ی شروع برنامه) |
| `calculator.py` | منطق ماشین‌حساب — مستقل از رابط کاربری |
| `test_calculator.py` | تست‌های خودکار (منطق + UI) |
| `buildozer.spec` | تنظیمات ساخت APK |
| `icon.png` / `presplash.png` | آیکون و صفحه‌ی شروع اندروید |
| `.github/workflows/build-apk.yml` | بیلد خودکار APK روی GitHub Actions |
| `build_apk_colab.ipynb` | نوت‌بوک آماده‌ی بیلد APK در Google Colab |
| `calculator.zip` | پروژه‌ی فشرده برای آپلود در Colab |

## اجرا روی ویندوز (برای تست)

```
pip install kivy
python main.py
```

کیبورد هم کار می‌کند: اعداد، `+ - * /`، Enter (مساوی)، Backspace و C (پاک کردن).

## ساخت خروجی APK

ساخت APK از **ویندوز مستقیماً ممکن نیست** — ابزار رسمی Kivy یعنی Buildozer فقط روی لینوکس اجرا می‌شود. دو راه آماده دارید:

### راه ۱ — Google Colab (ساده‌ترین؛ نیازی به نصب چیزی ندارد)
1. وارد [colab.research.google.com](https://colab.research.google.com) شوید و `build_apk_colab.ipynb` را باز کنید (File › Upload notebook).
2. سلول‌ها را به ترتیب اجرا کنید؛ وقتی خواست، فایل `calculator.zip` را آپلود کنید.
3. سلول بیلد حدود **۲۰ تا ۴۰ دقیقه** طول می‌کشد (فقط بار اول).
4. در پایان فایل APK دانلود می‌شود.

### راه ۲ — GitHub Actions (بیلد خودکار، رایگان)
1. یک ریپازیتوری در GitHub بسازید و همه‌ی فایل‌های این پوشه (به‌همراه پوشه‌ی `.github`) را آپلود کنید — حتی از طریق وب‌سایت و بدون git.
2. به تب **Actions** بروید؛ workflow «Build APK» خودکار اجرا می‌شود (حدود ۲۵ تا ۴۵ دقیقه برای بار اول).
3. از بخش **Artifacts** همان اجرا، فایل `calculator-apk` را دانلود کنید.

### راه ۳ — لینوکس/WSL (برای حرفه‌ای‌ها)
```
sudo apt update && sudo apt install -y automake autoconf libtool pkg-config
pip install buildozer "cython>=3.0,<3.1"
buildozer android debug     # خروجی: bin/*.apk
```

## نصب روی گوشی
فایل APK را به گوشی بفرستید و باز کنید. اگر پیام «نصب از منابع ناشناس» آمد، آن را برای مرورگر/فایل‌منیجر خودتان فعال کنید. معماری‌های `arm64-v8a` و `armeabi-v7a` پشتیبانی شده‌اند (تقریباً همه‌ی گوشی‌ها).

## تست‌ها
```
python test_calculator.py
```
۲۰ سناریوی منطقی (جمع، تفریق، ضرب، تقسیم، اعشار، تقسیم بر صفر، خطا و بازیابی از آن، پاک کردن و…) + تست ساخت رابط کاربری.
